# 📱 Projetos Redes Sociais (CURSO EM VÍDEO)

Este projeto é uma página web simples desenvolvida com **HTML e CSS**, que simula a interface de um smartphone exibindo diferentes páginas de redes sociais dentro de um `iframe`. O usuário pode navegar entre as páginas clicando nos ícones das redes sociais.

## 🧩 Estrutura do Projeto

📁 projeto/
├── index.html
├── stilos.css
├── favicon.ico
├── home.html
├── youtube.html
├── github.html
├── instagram.html
├── x.html

└── 📁 imagens/
    ├── logo-home.jpg

    └── logo-facebook.jpg

## 🚀 Como funciona

- O `index.html` é a página principal do projeto.
- Um `iframe` central simula a tela de um celular, exibindo as páginas internas (`home.html`, `youtube.html`, etc.).
- Os ícones das redes sociais estão dispostos ao lado, e ao clicar neles, o conteúdo do `iframe` é alterado conforme a rede social selecionada.
- O CSS está vinculado no arquivo `stilos.css`.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🖼️ Pré-requisitos

Para visualizar corretamente o projeto:

- Todos os arquivos `.html` mencionados (como `home.html`, `youtube.html`, etc.) devem estar presentes no mesmo diretório do `index.html`.
- As imagens devem estar na pasta `imagens/` e corresponder aos nomes utilizados no código.

## 🔧 Como usar

1. Baixe ou clone este repositório.
2. Certifique-se de que todos os arquivos estão organizados conforme a estrutura mostrada acima.
3. Abra o arquivo `index.html` em um navegador moderno.
4. Clique nos ícones das redes sociais para navegar pelas páginas dentro do `iframe`.

## 📌 Observações

- O projeto é apenas uma simulação de navegação em redes sociais e não está conectado com os sites reais.
- Você pode personalizar os ícones, as páginas internas e o estilo como preferir.
